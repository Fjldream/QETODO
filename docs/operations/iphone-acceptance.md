# iPhone 实机验收清单

执行环境：目标 iPhone、最新版 iOS、Safari、正式 HTTPS 域名。以下项目需要在实际手机上逐项勾选并记录日期；自动化测试不能替代推送和主屏幕行为验收。

## 安装与显示

- [ ] Safari 打开正式域名，无证书警告，也没有跳转循环。
- [ ] 分享 →“添加到主屏幕”，名称和图标正确。
- [ ] 从主屏幕启动后为独立窗口，无 Safari 地址栏。
- [ ] 刘海/灵动岛和底部 Home 指示条不遮挡标题、按钮、标签栏。
- [ ] 浅色、深色模式均清晰；系统大字体下可滚动且关键按钮不重叠。
- [ ] 开启“减少动态效果”后，不出现强制大幅动画。

## 日常质量工作流

- [ ] 新建普通、重要、紧急任务；截止日期、参考编号和灵活标签保存正确。
- [ ] “等待他人”缺少等待对象/跟进时间时阻止保存，补齐后可保存。
- [ ] 完成含未完成子任务的任务时出现确认；完成、取消、删除后可撤销或恢复。
- [ ] 今日、全部任务、日历、搜索和回收站均可用。
- [ ] 拍照上传后显示压缩前后大小；最多 6 张；详情中可查看和删除。

## 离线与恢复网络

- [ ] 打开应用一次后进入飞行模式，仍能从主屏幕启动并看到已缓存任务。
- [ ] 离线新建任务、强制关闭再打开，任务仍在且只有一条。
- [ ] 恢复网络后等待同步，再从另一浏览器确认服务端只有一条记录。
- [ ] 同步期间会话过期时操作不会丢失；重新登录后继续同步。

## 通知

- [ ] 只有点击“开启通知”后才弹系统授权框。
- [ ] 允许通知后，测试提醒能出现在锁屏和通知中心。
- [ ] 点击通知直接打开对应任务；拒绝通知时应用内逾期提示仍正常。
- [ ] 修改每日汇总时间后，下一次推送按 Asia/Shanghai 时间触发。
