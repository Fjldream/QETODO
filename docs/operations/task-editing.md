# 修改任务和记录处理进展

在“今日”“任务”或“日历”中点开任务，点击详情右上角的“编辑”。可修改标题、说明、状态、优先级、截止/提醒时间、重复规则、等待对象、跟进时间、关联编号和标签，也可以继续添加压缩图片。保存会更新原任务，保留已有图片、子任务和处理动态。

状态包含待处理、进行中、等待他人、已完成、已取消。“等待他人”必须填写等待对象和跟进时间；有未完成子任务时，改为“已完成”需要明确确认。要重新处理已完成或已取消的任务，在“任务”的状态筛选中找到对应任务，再编辑状态。

初始常用标签为检验检测、质量异常、整改跟进、供应商、外协、体系审核、资料报告、会议沟通。点击可选择或取消，也可输入自定义标签。初始标签不会自动套用到任务。

“任务状态”用于表示所处阶段，“处理进展”用于记录具体过程。点开任务，在“最新进展”旁点击“记录进展”，填写处理情况后保存。每次保存都是一条新记录，会记录时间，旧记录保留在“处理动态”。任务列表直接显示最近一条进展。

断网时编辑和进展记录先保存在手机；恢复网络后按顺序同步。更新部署后重新打开应用；若出现“新版本已准备好”，完成当前编辑和同步后再更新。

## 计划处理和整月日历

新建或编辑任务时，可单独设置“计划处理日期”。它表示哪天开始推进，不会修改截止时间；留空表示暂不安排。安排在今天及以前、尚未完成的任务会保留在“今日”的“计划处理”分组中。已超期或今天到期的任务优先归入对应分组，同一任务只显示一次。未设置计划的旧任务仍按原规则显示。

“日历”默认显示北京时间的当前整月，周一至周日排列，可切换上个月、下个月或回到今天。每天右下角的数字表示当天计划处理或到期的未完成任务数量；同一个任务当天既计划处理又到期时只计一次。已完成、已取消及回收站任务不计入。

点击日期，下方显示对应任务并注明“计划处理”或“到期”。计划日期与截止日期不同时，同一任务可以分别出现在两天，方便提前推进并关注最终期限。今日、任务和日历页面仅任务列表滚动；顶部标题、筛选、月历和底部导航保持固定。详情和编辑弹窗的内容独立滚动。
